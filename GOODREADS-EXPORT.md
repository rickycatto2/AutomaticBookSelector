# Manual-assisted Goodreads exports

**Goodreads export** lists completed ABS/BookRamp books not confirmed imported. Known Goodreads read-history entries are excluded, but every previously exported-unconfirmed ABS ID returns to the list even if it overlaps seed history. Duplicate completed editions and DNF-marked completions are no longer suppressed: err toward more books, since reimports are safe. Skipped books remain visible but not export-ready. The original Goodreads seed is retained. Previously imported to-read entries can supply candidate details, not acceptance.

## Everyday workflow

Each card shows **cover, title, author, Google search, ASIN-or-ISBN input, optional public stars, Save and Skip this book** without expanding anything. Covers use the existing authenticated `/api/cover?id=<ABS ID>` proxy, not a new external image provider. **More details ▾** edits title, full authors, genuine completion date and Goodreads link, and keeps optional catalog/page lookups available. The identifier is always editable in the main card. Save confirms your details, resumes a skipped title and selects it for **Export selected CSV**; it never asserts Goodreads imported anything.

Per-book states: **never-attempted**, **exported-unconfirmed**, **import-failed** (reason displayed), **returned-to-review**. Skipped and saved/ready are separate flags. **Confirmed imported** titles leave the working list and remain in export history. Exports remain unconfirmed until explicit user confirmation: either the latest batch title's **Confirm imported** button, or the reviewed report's explicit remaining-imports checkbox. Recognized success lines alone never mark a title imported.

### How to clear your queue

Import the exported CSV in Goodreads. Paste Goodreads' rejection output into the error box, tick **I checked that the other books in this batch imported successfully**, preview, resolve ambiguity with explicit failed-book selections, then **Save reviewed import result**. Only other still-exported rows are confirmed imported and leave the queue; unresolved ambiguity or unrecognized output blocks confirming the remainder. If there are no rejections, check the titles in Goodreads and use per-title **Confirm imported** in export history. Exporting alone does not clear the queue.

For a book you never want on Goodreads, use **Skip this book**, not export and re-upload. It remains visible but is excluded from exports and Goodreads suggestions until you **Save again**. There is no bulk clear or unchecked single-book removal shortcut. **Return to review** brings one unconfirmed book back into the working queue for correction, not import confirmation.

**Export history** lists all batches, not only the latest twenty. Expand **View individual titles** to see title/author/identifier/state, download again, or **Return to review** for a single unconfirmed title. Returning from an older batch updates that title's latest unconfirmed status and clears only its export-readiness confirmation; saved title, author, identifier, link, date, public stars, skip decision, context and historical CSV/item rows remain. Other titles are untouched. A latest confirmed import cannot be reset by this action. Cross-batch/unknown selections and stale import confirmations are rejected.

Review title, all authors/roles, an identifier (audiobook ASIN or catalog ISBN), the actual date completed, and optional **public** stars. Private feedback is never copied into this table and public stars never train recommendations. Per user preference, a correct print/Kindle/large-print/translated edition is acceptable; exact language/edition is not required. ISBN-10 leading zeros and X check digits are preserved, and ISBN-10/13 checksums are validated without change. ASIN syntax is exactly ten uppercase alphanumeric characters, with no whitespace/control characters. Dates from ABS millisecond/ISO timestamps are converted to America/Chicago. Missing/future completion dates block exports until you enter the genuine date; a sync/import date is never substituted. **Goodreads acceptance of any identifier remains unverified by the app.** Use a one-book manual import and return failures below.

### ABS audiobook ASIN identifiers

The user verified a real Goodreads CSV import with an ASIN in the **ISBN** column, and another with a real audiobook ISBN. That observation is not a guarantee for another identifier or edition. ABS supplies `media.metadata.asin` for roughly 87% of sampled books (174/200); AudiobookFunnel writes it as an iTunes freeform atom. This app uses that supplied value directly, with no Audible API or identifier guessing. UI provenance explicitly calls it an **ASIN from your audiobook edition**, never an ISBN. Catalog ISBNs remain a fallback.

Sync adds `books.asin TEXT NOT NULL DEFAULT ''` through an idempotent additive migration like `language`. Existing rows receive an empty value; non-string/blank incoming values do not erase a previous ASIN. Nonblank changes invalidate export confirmation without deleting details; adding the empty column preserves old snapshots. A valid source ASIN is preferred unless a saved manual decision exists. Optional matching can fill the owned ASIN locally without providers, but now records an **unconfirmed suggestion**, never readiness. Save is required. Failed imports and saved/stale decisions still require explicit review; dates are never fabricated.

## Bounded automatic check and explicit free catalog action

**Loading this page makes no provider calls.** Catalog matching is an optional convenience. The retained authenticated `/api/goodreads/auto-resolve` endpoint remains bounded to one undecided book per explicit call, ten books per rolling day/process, five-second pacing and at most two provider requests per book; the normal UI no longer calls it on load. Durable attempted fingerprints prevent repeated matching across restarts. Existing manual/failed decisions are protected. High-confidence evidence may fill unconfirmed suggestion fields but cannot make a book export-ready: review and Save yourself. No transport, cache, rate or key handling changed.

### One-click matching of eligible completions

**Match eligible books** explicitly creates/resumes a durable queue of **at most 25 eligible completions**, not the Goodreads seed. Existing saved/manual/failed decisions and attempted fingerprints are excluded. Queue creation makes no provider calls. The browser resolves **one book per request** plus queue ID, waiting five seconds before every request. Existing provider throttles and the two-request ceiling remain unchanged. Progress shows **suggested (Save required)**, review, skipped and provider-error/interrupted counts; legacy matching-job `ready` labels are presented as suggestions too.

**Pause matching** stops before the next request. A request already in flight may finish and persist its result. Closing the page starts no further requests; reopening shows the saved queue and resuming requires another button press. The queue cannot grow during resume. An attempt is claimed durably before lookup: duplicate/concurrent requests or interrupted requests are never silently repeated. An interrupted attempt stays review-only; use the existing per-book explicit resolver to retry deliberately. Provider errors and throttle results are retained, not automatically retried. Source/decision/export changes while paused cause queued items to be skipped; they do not overwrite existing decisions. Finishing a queue permits a new explicit queue only for still-undecided, previously unattempted books.

Low-confidence candidate suggestions, ambiguous catalog evidence and reasons persist across refresh/restart and are displayed separately from the user's saved form. They do not confirm a book or overwrite saved fields. Copy/review suggested details (or use the per-card resolver), confirm, and save manually. Unknown/different language is neutral and labeled an edition difference; conflicting authors/work identities and unlinked Open Library ISBNs remain review-only. Missing dates are never invented. The batch refuses to start with unsaved edits and makes book forms inert while running; pause to edit. No ABS writes, paid calls or Goodreads uploads are introduced. Existing export and failed-import reconciliation actions remain explicit.

**Re-check nothing found / ambiguous books (up to 25)** explicitly queues only already-attempted, unchanged completed books whose last persisted outcome has no selected candidate and no high-confidence match. Ambiguous candidate lists are eligible; a selected low-confidence candidate still needs per-book review. Saved decisions (automatic, manual, unconfirmed or ignored), failed imports, source changes, provider-blocked/interrupted outcomes and duplicate-work skips are excluded. Provider blocks keep their separate retry action. The authenticated `/api/goodreads/recheck` creates/resumes a fixed queue without lookup; repeated clicks while queued/in flight return the same queue. The existing five-second browser pacing, one-book requests and durable claim-before-lookup apply. Attempts are never deleted: a fresh outcome replaces the same book+snapshot attempt, so counts remain meaningful. A finished no-match outcome can be deliberately re-checked again, never automatically.

Synthetic browser regression: serve `tests/test_goodreads_batch_browser.html` and `static/` on loopback, open the test page, and require its **PASS** result. It uses real DOM elements, a virtual five-second clock and a fake durable API to cover progress, rate, 25-book cap, pause while waiting/in flight, page-close resume and all counts; it never loads a user database or contacts catalogs.

**Find work ISBN (free catalogs)** uses the review form's current validated title and author, including unsaved corrections, and returns an unconfirmed suggestion. It never reloads/discards unsaved forms or automatically saves the result. Existing edits and saved reviewed identifiers are retained; suggestions are displayed for review. Batch, re-check and automatic actions keep using synced source metadata (and prefer a valid supplied ASIN locally). Catalog fallback uses Google Books, then Open Library if Google is unavailable, has no exact work, or lacks a valid ISBN. When the source author has narrator/translator role words or equals the nonempty narrator name set, retrieval uses the title alone rather than filtering out the real author; identity checks still retain the unchanged source author. Google Books is anonymous unless optional `GOOGLE_BOOKS_API_KEY` is set in the server environment; that credential is sent only to Google server-side, never to the browser or Open Library. Only title/author search terms are sent: never narrator, private feedback, ratings, descriptions, reading state, dates, or ABS credentials. Nothing is uploaded to Goodreads.

Provider failures show only provider, status and a safe explanation, not response bodies or request URLs. HTTP 429 suppresses that provider until the next UTC day boundary locally (not a promised provider reset); transport/timeout failures use a 60-second backoff. Restart or a changed provider credential clears that in-process cooldown; the five-second spacing still applies. Durable attempt records remain. **Retry provider-blocked books (up to 25)** explicitly creates a one-book-per-request queue only for quota/transport failures without candidates, saved decisions or failed imports. It does not erase attempts or retry review outcomes. Provider-blocked cards say lookup could not run and remain blocked from export.

Evidence score is 0–100, with auto threshold **90 plus linked ISBN identity**: exact normalized work title +40, independently corroborated full author set +35, checksum-valid catalog ISBN +15, linked edition identity +10. Language is neutral (+0). A catalog-added non-series subtitle with the exact same base title and full author evidence counts as exact work evidence (+40), including short base titles; its catalog title and author are saved/exported. A source-only subtitle retains the conservative three-word/twelve-character base rule (+35). Two conflicting subtitles, differing base titles and conflicting volume/part/#/series markers remain review-only; series positions are never edition differences. There is no fuzzy title matching. Matching catalog candidates must agree on the complete author set and cannot carry contributor role words. For role-filled or narrator-equal source authors, a unanimous catalog author set may replace the ABS string, but every unlabelled source contributor other than a known narrator must remain in that set; a role label cannot silently drop a coauthor. No names are stripped from ABS. The original ABS author stays visible on the review card and the full catalog author is used for save/export. Narrator==author is described as self-narration only when the catalog confirms that same full name set; otherwise catalog authors take precedence. Genuine role conflicts still require review; fallback never launders work/series conflicts. A truncated page may auto-confirm only when all matching candidates agree on one accepted exact work title key and full catalog author set, with no conflicting subtitle/volume marker and a valid ISBN on every candidate. Differing work keys (even bare and subtitled titles together on a truncated page), author sets or missing ISBNs still force review. Multiple Google volumes with the same work/full authors may auto-confirm; selection is deterministic, preferring publisher/print evidence, then ISBN-13 and stable ISBN/ID ordering. These are evidence scores, not calibrated probabilities or proof of Goodreads acceptance. Unsafe fields and duplicate candidate work/ISBN in prior read/export records prevent automation; existing saved/failed decisions remain untouched.

Open Library aggregated **work-level** ISBNs remain suggestions only. Auto-confirmation requires a unique valid work ID with full author evidence and an included edition record with its own book ID, matching work/full author set, and checksum-valid ISBN. The two-provider/two-request ceiling is unchanged: no additional edition fetch is launched. If search does not expose this evidence (as is common), review remains required. Multiple distinct work IDs block selection. No language inference or source corrections are required.

Searches are capped at ten records. Export/download still requires the explicit existing export button; there is no automatic upload/download.

Existing manual/automatic/failed decisions are never overwritten by resolution. Saved matches retain a separate source-metadata fingerprint (ABS ID/title/full author/ISBN/nonblank ASIN/language/narrator) and provenance/evidence. Changed source metadata or legacy matches with no fingerprint block readiness while retaining all old match records. Reload and explicitly re-review/save to bind them to the new source; an open UI form's old fingerprint is rejected after a concurrent sync. Legacy confirmations are not destructively migrated. Failed imports remain unconfirmed and are never automatically retried.

Read-history matching still uses normalized work title/full authors and canonical identifier equivalence. The working queue no longer deduplicates unknown completed editions or hides unconfirmed exports; explicit latest imported state excludes that ABS ID. Matching suppresses suggestions for confirmed read-history/imported identities, not unconfirmed exports. Historical CSV bytes and item rows are retained. Identically named works and valid-but-wrong identifiers still require user judgment.

The CSV keeps exactly `Title,Author,ISBN,My Rating,Date Read,Shelves`. The chosen **ASIN or ISBN goes in the existing ISBN column**; this schema label does not turn an ASIN into an ISBN. Date Read is always present and nonblank, in YYYY-MM-DD format, and Shelves is always read. The generator uses the standard CSV writer and delivers UTF-8 with BOM from the browser; unsafe formula-style identifiers are rejected. Goodreads may accept fields differently for existing reviews and rereads; one-book testing is still necessary. There is no supported guarantee that a CSV creates social-feed entries.

**Find Goodreads match** opens a `site:goodreads.com/book/show <title> <first author> audiobook` web search. Both search links use only the author before the first comma or semicolon, avoiding narrator-filled metadata without changing saved/exported authors. **Find print/ebook edition** retains additional paperback/hardcover/print terms. Both safely percent-encode the current form values, including odd or empty fields; nothing is crawled and no request goes to Goodreads. Paste a Goodreads book URL and press **Get ISBN from link** to retrieve structured ISBN metadata from the public book page. It is a bounded, explicit, rate-limited request, with no Goodreads credentials, redirects, proxy rotation or challenge bypass. Search crawling is not implemented because Goodreads' robots.txt disallows `/search`. An ASIN-only audiobook page has no ISBN to extract; the lookup then says so and points you to **Find print/ebook edition** or **Find work ISBN (free catalogs)**. Any page without a usable ISBN (often a Kindle edition) needs Book details & editions on a print edition, with the ISBN copied manually. When the form's ISBN passes the checksum, **Open Goodreads edition for this ISBN** appears as a direct `https://www.goodreads.com/book/isbn/<ISBN>` link; this is only a convenience redirect — a valid checksum never asserts that Goodreads recognizes or imports that ISBN. Fix narrator-filled ABS authors in the export form; this does not rewrite ABS metadata.

Export atomically saves the CSV and item rows as **exported**, displayed as **exported-unconfirmed**. Those books remain available in subsequent exports until explicitly confirmed imported; no automatic acceptance migration runs for old exports. **Download again** reuses saved bytes. Returning an individual title does not delete a batch or its saved decisions.

Paste Goodreads' output into **Preview import result**, inspect the per-book states/reasons and proposed failures, then **Save reviewed import result**. Mixed reports are supported conservatively: a success line never becomes an inferred failure. Detection recognizes Goodreads' `1 book could not be imported:` / `ISBN<TAB>Title<TAB>Author` table (including blank Title), explicit leading failure statuses (`Failed:`, `Could not import:` etc.) or a `Failed books` section. Reconcile recognises both exact checksum-valid ISBNs (ISBN-10/13 equivalents count) and valid ASINs in the batch's existing ISBN field, or a whole `Title by Author` payload, not substrings. Blank-Title table rows copied with spaces instead of tabs require the exact exported author as well as the identifier. Table count mismatches, unsupported formats, missing context, shared identifiers and conflicting statuses require explicit per-book selection. **Choose failed books manually** is always available; selections use ABS IDs, not titles. Manual selections cannot silently erase detected failures. A selected book with a recognized success line is rejected until the contradictory report/selection is corrected.

Failed items feed this same working list, changing state/reason and clearing export confirmation until saved again. Only explicit boolean confirmation can mark other still-exported rows imported, after identified failures/successes or explicit nonempty failure selection resolve ambiguity. Empty input is a no-op; unknown prose alone never imports the remainder. Historical CSVs/IDs remain; reprocessing a failure does not clear a newly saved match again. Old failures cannot invalidate newer exports, and exceptions roll back the entire transaction. Reasons are bounded to 500 characters; the whole report is not stored. No reconciliation network calls or private feedback access occur.

It was not missing a completion date and no CSV column shift was found. Goodreads' rejection does not establish an exact cause. An unrecognized audiobook edition is a plausible explanation.

The app's public-page lookup succeeded for https://www.goodreads.com/book/show/241504373 and retrieved Goodreads-listed ISBN **9781399633413**, the full title, and Lindsay Owens as primary author. This gives a Goodreads-listed identifier to try instead of an unrecognized audiobook ISBN. Review the completion date from ABS before exporting; it can differ from an earlier manually prepared file.
