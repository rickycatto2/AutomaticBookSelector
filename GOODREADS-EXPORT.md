# Reviewed Goodreads exports

**Goodreads export** lists completed ABS/BookRamp books absent from the imported Goodreads read history. DNF, ignored, already exported and duplicate editions are excluded. The original Goodreads seed is retained. Previously imported to-read entries can supply a candidate edition/full author list; these remain unconfirmed until reviewed.

Review title, all authors/roles, an ISBN for the same work and language, the actual date completed, and optional **public** stars. Private feedback is never copied into this table and public stars never train recommendations. A correct print/ebook/large-print edition is fine, not necessarily audio. ISBN-10 leading zeros and X check digits are preserved, and ISBN-10/13 checksums are validated. Dates from ABS millisecond/ISO timestamps are converted to America/Chicago. Missing/future completion dates block exports until you enter the genuine date; a sync/import date is never substituted. **A valid checksum or external catalog listing does not guarantee Goodreads will import an ISBN.** Use a one-book manual import and return failures below.

## Bounded automatic check and explicit free catalog action

Loading the Goodreads list automatically checks **at most one undecided book** using anonymous free catalogs. The server caps this at **ten books per rolling 24 hours per process**, spaces attempts by at least five seconds, and caches attempted source fingerprints (including uncertainty/errors) for 24 hours. Each book can make at most two provider requests. Concurrent loads do not multiply requests; there is no per-card loop, timer, bulk scheduler or automatic retry. Restart resets these in-memory bounds. Large libraries are deliberately not searched in full. Existing saved decisions and failed imports are never searched automatically. The UI does not replace unsaved edits after a slow check. High-confidence evidence can save an ISBN and make the book ready without another action; uncertain metadata remains in review with the reason displayed.

**Find work ISBN (free catalogs)** remains available explicitly. Both paths send only the synced source title and complete author string to the anonymous Google Books API, then Open Library if Google is unavailable, has no exact work, or lacks a valid ISBN. No API keys, paid services, reviews, ratings, descriptions, reading state, dates, or ABS credentials are sent. Nothing is uploaded to Goodreads. Searches operate on synced source metadata, not unsaved form edits.

Google suggestions become ready automatically only with exact normalized full title (subtitles retained; a narrow explicit audio/format suffix may be ignored), full author-name set equality, known matching source/catalog language, checksum-valid ISBN and an existing genuine completion date. Same-title author conflicts, missing/conflicting language, truncation and uncertain contributor roles require review; fallback never launders such conflicts. Authors are not stripped using narrator/preferred-author heuristics. Multiple Google volumes require a shared checksum-valid edition identifier (ISBN-10/13 equivalents count); otherwise work linkage is unknown and requires review, even if they might be legitimate editions of one work. This is high-confidence bibliographic evidence, not Goodreads acceptance or a guarantee against incorrect upstream catalog metadata.

Open Library search returns aggregated **work-level** ISBNs/languages. It is therefore a review-only fallback suggestion in this increment: edition-level author/language linkage is not yet automated. Multiple distinct Open Library work IDs block even that single candidate selection. Unknown source language must be corrected in ABS and synced, or manually reviewed; only English/German/French/Spanish codes/names are currently normalized.

Transport uses fixed HTTPS endpoints `www.googleapis.com/books/v1/volumes` and `openlibrary.org/search.json`, TLS verification, disabled environment proxies, no credentials/cookies/redirects, 10-second timeout and a 1 MB response cap. Searches are capped at ten records. Each provider permits one uncached request per five seconds; a 128-entry in-memory cache lasts 24 hours. `/api/goodreads/resolve` accepts 1–10 distinct queued ABS IDs, processes sequentially, and returns rate-limited items for review rather than sleeping or launching unbounded retries. `/api/goodreads/auto-resolve` implements the tighter automatic bounds above with the same authentication/origin protections. Export/download still requires the explicit existing export button; there is no automatic upload/download.

Existing manual/automatic/failed decisions are never overwritten by resolution. Saved matches retain a separate source-metadata fingerprint (ABS ID/title/full author/ISBN/language/narrator) and provenance/evidence. Changed source metadata or legacy matches with no fingerprint block readiness while retaining all old match records. Reload and explicitly re-review/save to bind them to the new source; an open UI form's old fingerprint is rejected after a concurrent sync. Legacy confirmations are not destructively migrated. Failed imports remain unconfirmed and are never automatically retried.

Export/history/queue dedup now uses full normalized work title plus full author set, and prior exported ABS IDs; it no longer uses title alone or drops arbitrary subtitles. Existing export rows/CSVs/states are unchanged. Same-title different-author works remain visible. Identically named same-author works cannot reliably be distinguished without additional evidence, and same-work translations/abridgements still need manual review; this increment does not reclassify historical editions.

The CSV has `Title,Author,ISBN,My Rating,Date Read,Shelves`. Date Read is always present and nonblank, in YYYY-MM-DD format, and Shelves is always read. The generator quotes commas/newlines through the standard CSV writer and delivers UTF-8 with BOM from the browser. Goodreads may accept fields differently for existing reviews and rereads; one-book testing is still necessary. There is no supported guarantee that a CSV creates social-feed entries.

**Find Goodreads match** opens a title/primary-author web search. Paste a Goodreads book URL and press **Get ISBN from link** to retrieve structured ISBN metadata from the public book page. It is a bounded, explicit, rate-limited request, with no Goodreads credentials, redirects, proxy rotation or challenge bypass. Search crawling is not implemented because Goodreads' robots.txt disallows `/search`. Their page may deny automated lookup or have no ISBN (often a Kindle edition). In that case use Book details & editions, open a print edition and copy its ISBN manually. Fix narrator-filled ABS authors in the export form; this does not rewrite ABS metadata.

When you export, the batch CSV and its item records are saved atomically and the items are marked **exported** immediately. Subsequent batches contain only new/failed works. **Download again** reuses the saved batch if a browser download fails. Goodreads import confirmation is separate from export state.

Paste Goodreads' output into **Preview import result**, inspect the per-book states/reasons and proposed failures, then **Save reviewed import result**. Mixed reports are supported conservatively: a success line never becomes an inferred failure. Detection recognizes Goodreads' `1 book could not be imported:` / `ISBN<TAB>Title<TAB>Author` table (including blank Title), explicit leading failure statuses (`Failed:`, `Could not import:` etc.) or a `Failed books` section. It requires an exact checksum-valid ISBN token (ISBN10/13 equivalents count) or a whole `Title by Author` payload, not substrings. Table count mismatches, unsupported formats, missing context, shared ISBNs and conflicting statuses require explicit per-book selection. **Choose failed books manually** is always available; selections use ABS IDs, not titles. Manual selections cannot silently erase detected failures. A selected book with a recognized success line is rejected until the contradictory report/selection is corrected.

Failed items alone return to review with confirmation cleared, requiring a corrected match before retry. Only explicit boolean confirmation can mark other still-exported rows imported, and only after identified failures/successes or explicit nonempty per-book failure selection resolve ambiguity. Empty input is a no-op; unknown text alone never imports the remainder. Historical CSVs/IDs are retained; reprocessing an old failed result does not clear a newly reviewed match again, and an old batch cannot invalidate a newer retry export. Reasons are stored/displayed per book, bounded to 500 characters; the whole pasted report is not stored. Reconciliation has no network calls and does not access private feedback. Nothing is uploaded to Goodreads by this app.

## Gouged failed-file investigation

A test row for *Gouged* used 14 headers/14 values, valid audiobook ISBN `9798217356157`, a populated Date Read, and Shelves `read`. It was not missing a completion date and no CSV column shift was found. Goodreads' rejection does not establish an exact cause. An unrecognized audiobook edition is a plausible explanation.

The publisher lists a print edition of *Gouged: The End of a Fair Price—and What That Means for Your Wallet* by Lindsay Owens with ISBN **9798217058785**. The app's public-page lookup succeeded for https://www.goodreads.com/book/show/241504373 and retrieved Goodreads-listed ISBN **9781399633413**, the full title, and Lindsay Owens as primary author. This gives a Goodreads-listed identifier to try instead of an unrecognized audiobook ISBN. Review the completion date from ABS before exporting; it can differ from an earlier manually prepared file. CSV acceptance, challenge count and feed behavior still require a real manual import. Test CSVs and personal completion dates are kept outside the repository.
